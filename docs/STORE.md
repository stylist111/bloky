# Публикация в магазине Chrome

Картинки для страницы магазина собираются скриптом `tools/bloky/art/make_store.py` в `_build/store/`
(из скриншотов, которые делает `tools/bloky/dev/check.mjs`).

## Один раз: аккаунт разработчика

1. Откройте https://chrome.google.com/webstore/devconsole и войдите в Google-аккаунт,
   от имени которого будет опубликован Bloky.
2. Примите соглашение и оплатите регистрацию — **$5 один раз**.
3. Подтвердите почту для связи (письмо придёт на неё). Без этого опубликовать нельзя.

## Новая публикация

В консоли: **«Новый элемент»** → загрузите архив `bloky-chrome-<версия>.zip`
из [релиза](https://github.com/stylist111/bloky/releases/latest). Затем заполните вкладки слева.

### «Описание в магазине»

**Название и краткое описание** подставятся из архива сами.

**Описание:**

```
Bloky — бесплатный блокировщик рекламы. Все функции бесплатны сразу: никаких подписок, пробных периодов и рекламы самого себя.

Что умеет:
• Убирает рекламу на сайтах, а заодно счётчики и трекеры
• Скрывает отвлекающее: всплывающие окна, просьбы подписаться, уведомления сайтов
• Скрывает окна про cookie на популярных сайтах
• Правый клик → «Скрыть что-то на этой странице», если реклама всё-таки проскочила
• «Приостановить на этом сайте», если сайт без рекламы не работает
• Темы оформления и замена рекламы на ваши картинки

Чего не делает:
• Не собирает данные и не отправляет статистику
• Не показывает свою рекламу и не уговаривает что-то купить
• Не пропускает «ненавязчивую рекламу» — она выключена (включить можно в настройках)

Bloky сделан на основе открытого кода AdBlock (лицензия GPLv3) и не связан с AdBlock и eyeo.
Исходный код: https://github.com/stylist111/bloky
```

**Категория:** выберите ту, где в магазине стоят другие блокировщики рекламы
(сейчас это раздел про конфиденциальность и безопасность, если он есть в списке; иначе «Инструменты»).

**Язык:** русский.

**Картинки** (из `_build/store/`):

- значок магазина 128×128 — `icon-128.png`;
- скриншоты 1280×800 — `screenshot-1.png` … `screenshot-4.png`;
- малая плитка 440×280 — `promo-440x280.png`.

**Сайт:** https://github.com/stylist111/bloky  
**Поддержка:** https://github.com/stylist111/bloky/issues

### «Конфиденциальность»

**Единственное назначение:**

```
Блокировка рекламы и других мешающих элементов (всплывающих окон, окон про cookie, трекеров) на сайтах.
```

**Зачем нужны разрешения** — вставьте в поле каждого разрешения:

| Разрешение                          | Текст                                                                                                                                                                                                                                        |
| ----------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| declarativeNetRequestWithHostAccess | Блокирует запросы к рекламным серверам и трекерам по спискам фильтров.                                                                                                                                                                       |
| Доступ к сайтам (host permissions)  | Нужен, чтобы скрывать рекламу на любом сайте, который открывает пользователь. Содержимое страниц не покидает компьютер.                                                                                                                      |
| scripting                           | Вставляет на страницу стили, скрывающие рекламные элементы, и открывает инструмент «Скрыть что-то на этой странице».                                                                                                                         |
| tabs                                | Показывает число заблокированной рекламы и состояние для текущей вкладки, открывает страницу настроек.                                                                                                                                       |
| webNavigation                       | Применяет правила скрытия ко всем фреймам страницы во время загрузки.                                                                                                                                                                        |
| webRequest                          | Считает заблокированные запросы для счётчика и применяет исключения, которые задал пользователь.                                                                                                                                             |
| storage, unlimitedStorage           | Хранит настройки, правила пользователя и большие списки фильтров локально в браузере.                                                                                                                                                        |
| alarms                              | Периодически проверяет обновления списков рекламы.                                                                                                                                                                                           |
| contextMenus                        | Добавляет в меню правой кнопки пункты «Скрыть что-то на этой странице» и «Приостановить на этом сайте».                                                                                                                                      |
| idle                                | Откладывает фоновое обслуживание (обновление счётчиков, очистку старых данных) до момента, когда браузер простаивает.                                                                                                                        |
| management (необязательное)         | Запрашивается, только когда пользователь сам сохраняет файл с отладочной информацией на странице «Поддержка»: в файл добавляется список установленных расширений, чтобы найти конфликт с другим блокировщиком. Файл остаётся у пользователя. |

**Удалённый код:** «Нет, я не использую удалённый код». Списки фильтров — это данные, а не код.

**Использование данных:** не отмечайте ни одного типа данных. Поставьте все три подтверждения
(данные не продаются, не используются для посторонних целей, не используются для кредитных решений).

**Политика конфиденциальности:** https://github.com/stylist111/bloky/blob/main/PRIVACY.md

### «Распространение»

- Видимость: **Общедоступный**.
- Регионы: все.
- Цена: бесплатно.

Нажмите **«Отправить на проверку»**. Проверка обычно занимает от нескольких дней до пары недель —
блокировщики рекламы проверяют дольше обычного. Результат придёт письмом.

## После публикации

1. Скопируйте ссылку на страницу Bloky в магазине.
2. Замените в `README.md` строку «Из магазина Chrome — ссылка появится здесь после публикации» на ссылку.

## Новая версия

1. Выпустите версию (см. [BUILD.md](BUILD.md)) — GitHub соберёт архив в релизе.
2. В консоли: Bloky → **«Пакет»** → **«Загрузить новый пакет»** → архив из релиза → **«Отправить на проверку»**.
   После проверки магазин сам обновит Bloky у всех пользователей.

## Если отклонили

В письме указана причина и пункт правил. Частые причины у блокировщиков:
лишние разрешения, описание не совпадает с тем, что расширение делает, похожесть на чужой бренд.
Исправьте, загрузите новый пакет и отправьте снова; при несогласии можно подать апелляцию по ссылке из письма.
